# Connected app icons

Google Drive, Gmail and Calendar are unmodified SVG Logos paths. Outlook is the unmodified Simple Icons mark. Sources and SHA-256 hashes are pinned in provenance.json to Iconify icon-sets revision ff91f5f9c3b1ffad7f3e91f7f7f8c739edd57544; both source collections use CC0-1.0. SVG wrappers use the source dimensions. Trademark rights remain with the respective owners; these icons identify services and do not imply endorsement. No runtime logo requests are made.

Google Contacts, OpenTable, Outlook Calendar and Outlook People use Lucide category glyphs rather than imitations of unavailable brand artwork.
