# Extension catalog brand icons

These 30 SVG files are an unmodified subset of [Simple Icons](https://github.com/simple-icons/simple-icons), pinned to revision [`90646e4bf7f3b89df6c37e65baf3e7bc759a517c`](https://github.com/simple-icons/simple-icons/tree/90646e4bf7f3b89df6c37e65baf3e7bc759a517c). They identify services in the MuseBench catalog. Their presence does not imply endorsement or native compatibility.

The Simple Icons collection is distributed under **CC0-1.0**. Individual brand marks remain subject to their owners' trademark, copyright, and usage requirements; the collection license does not override those. See the included upstream [LICENSE.md](LICENSE.md) and [DISCLAIMER.md](DISCLAIMER.md). [provenance.json](provenance.json) records the exact SVG source, publisher source, brand guidance where supplied upstream, and license metadata for every bundled icon. A null individual license means upstream supplies no individual license metadata, not that the mark is unrestricted.

The component renders these local assets as CSS masks. Original shapes are unchanged; colors follow upstream brand metadata, with theme-aware monochrome for dark marks. Missing brands use generic Lucide category icons. There are no runtime requests for remote logos and no additional dependency.
