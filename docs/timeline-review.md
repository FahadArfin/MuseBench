# Prompt timeline and shared web login review

Self-review, 26 October 2026. No independent agent review was performed.

- One shared DOM-only timeline is used by React and the guarded personal-page installer. It reads rendered explicit user/assistant roles, uses textContent for previews, and only changes scroll position. It invokes no tool, submission, account API, storage or network request. Remote transcripts remain in their own sandboxed page; no new IPC was introduced.
- Mutation and resize observers update new messages and streamed excerpts, with refresh throttling. Entries track actual node identity, so repeated text remains distinct. Replaced conversations discard stale nodes; unmount and original-layout restoration disconnect observers and remove the Shadow DOM host. Existing account/navigation ownership still controls remote documents.
- Prompt navigation preserves unsent drafts. Keyboard focus previews without jumping; Enter/click performs a jump. Home/End, arrows and PageUp/PageDown are supported. Tooltip geometry is bounded to the viewport. Long rails are scrollable and keep the current prompt reachable. Tick-based navigation cannot recover older messages the service has not rendered.
- Muse Code previously hid every later user message identical to the initial request. Filtering now suppresses only an initial Muse request echo; repeated prompts remain visible and independently navigable. Manual notes are never deduplicated.
- The login block was reproduced through the official Meta AI Login button: www.meta.ai -> auth.meta.com -> auth.meta.ai. Only the final exact HTTPS host was added, including authentication-state tracking. Lookalikes, credentials in URLs, unsafe schemes, arbitrary subdomains, nested popups, device access and unsupported redirects stay blocked.
- Both personal services reuse the existing Muse session partition. No cookie contents were inspected, exported or copied. The prior Chat partition is retained on disk. Same-origin storage rules and separate page objects preserve service drafts. Tests verify shared session identity and cache invalidation for top-level authentication and popup authentication at both boundaries.
- Meta System theme now follows Electron nativeTheme after the finite appearance command validates. Live packaged Meta renders dark and retains its login. An explicit website theme remains controlled by Meta. CLI credentials, runtime flags, process supervision, approval settings, speech helper and sandbox execution were not changed.
- 303 unit tests and 84 packaged UI checks pass. Read-only saved-profile checks confirm both logins, Muse account collections, Meta dark appearance, retained local history and browser sandbox/context-isolation/web-security settings. Neither live saved chat had enough prompts to exercise a visible rail, so scroll interaction evidence uses fictional chats with the official structural hooks. No model or account-content write was performed.
