# Changelog-informed MuseBench roadmap

Requested 29 October 2026: research the supplied Grok Bot, ChatGPT/Codex and Claude Code changelogs, add worthwhile gaps, and implement them feature by feature. This supplements the existing remaining-feature inventory; it does not reset completed work.

## Sources and selection

- [Grok Bot, 0.78.1 / 0.77 / 0.75](https://x.ai/changelog/bot): useful directions include rich reply copying, resilient question cards, clearer connector identities and setup recovery, compact attachment handling, and update blockers that identify affected work. Shopping, payment vaults and subscription cancellation depend on services outside MuseBench's current product contract and are not selected.
- [ChatGPT/Codex, October 2026](https://learn.chatgpt.com/docs/changelog): useful directions include consistent Markdown in questions, recoverable queued text and images, focused connection diagnostics, stable reconnect views, faster transcript navigation, and clearer approval recovery. OpenAI model names, entitlements, cloud services and provider-specific execution are not transferable Muse features.
- [Claude Code, 2.1.312 / 2.1.311](https://code.claude.com/docs/en/changelog): useful directions include explicit queued-send controls, truthful active versus requested effort, precise connection failures, delayed-service handling, bounded background work and more responsive large sessions. Claude-only APIs and implicit model fallback are not selected.
- [OpenCode 2](https://anoma.ly/notes/opencode-2-0/), [current releases](https://github.com/anomalyco/opencode/blob/dev/CHANGELOG.md), [compaction](https://opencode.ai/v2/docs/compaction/), [GUI plugins](https://opencode.ai/v2/docs/build/plugins/gui): carry forward the six recommendations in the preceding conversation. Existing MuseBench snapshots, worktrees, persistent native history, goals, permissions and catalog are foundations, not new deliveries.

Sources were read on 29 October 2026. These are independent MuseBench designs inspired by public product behavior, not claims that another product's implementation can be copied directly. No additional model run is authorized by this research; the prior bounded model test was consumed.

Background model warming stays off: it makes actual provider requests during idle time. No speculative summary or hidden inference will be added to normal startup. Provider-only functions that fail contract investigation remain explicitly unavailable with evidence and a concrete prerequisite, rather than being replaced with a simulation.

## Existing capabilities to retain

Native Muse remains the backend. Preserve profile/session data, exact run receipts, reviewed MCP/plugin/hook grants, semantic navigation, app-owned checkpoints/redo, explicit worktree ownership, full-access/approval choices, durable drafts, history/search, usage provenance, and platform release matrix. No personal billing, account credentials, or machine-specific artifacts belong in Git.
