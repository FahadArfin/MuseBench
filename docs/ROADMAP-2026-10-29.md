### Codex feature review, 29 October

The [feature index](https://learn.chatgpt.com/docs/features) was compared with the current repository. The useful gaps below extend this queue; existing worktrees, drafts, checkpoints, native controls, OS notifications, catalog imports and Meta AI schedules are not counted again.

- [Local environments](https://learn.chatgpt.com/docs/environments/local-environment) and [terminal](https://learn.chatgpt.com/docs/integrated-terminal): reusable project actions are a good next step. MuseBench already owns cancellable check processes; extend that execution path with reviewed, portable action definitions before considering a full interactive terminal.
- [Notifications and Activity](https://learn.chatgpt.com/docs/notifications): retain completion and attention events in an inbox so work is still discoverable after it stops appearing in the running-work menu. OS delivery remains separate from the observed result.
- [Scheduled tasks](https://learn.chatgpt.com/docs/automations): add explicitly enabled local Code schedules with run limits, pause controls and missed-run/overlap handling. Local work requires the app and computer to be running; this is separate from Meta AI's hosted schedules.
- [Import](https://learn.chatgpt.com/docs/import): offer a preview of selected conversation exports and import them as local history. Do not transfer native session identity, credentials, execution permissions or executable configuration with a transcript.
- [Code review](https://learn.chatgpt.com/docs/code-review): extend OC02 with file review markers bound to a diff revision and editable feedback that identifies exact files and lines. Changed files must become unreviewed; drafting feedback must not send it.
- [Browser annotations](https://learn.chatgpt.com/docs/annotations-extensibility): a selected preview element can become useful source context for an unsent change request. Target/page identity and a bounded visible excerpt are sufficient; page content remains untrusted.

Delivery order: finish the in-progress diagnostics and updater/navigation work, then the activity inbox and project actions, followed by review feedback, imports, scheduling and preview annotations. A full terminal, floating pets and provider-specific cloud services are not selected for this pass.
