# Composer implementation plan

**Goal:** Implement the referenced composer with real reasoning, sandboxed approval choices and local dictation.
**Architecture:** Shared finite run-option validation; persisted per-task settings passed by the controller to native exec. A compiled fixed-purpose System.Speech helper is owned by a main-process dictation service with a narrow trusted-sender IPC. A focused React composer replaces the existing form.
**Stack:** Existing React/TypeScript/CSS, Electron, Node and Windows .NET Framework.
**Spec:** ../specs/2026-10-25-composer-design.md
