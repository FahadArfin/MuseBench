# Muse Code composer

Use the four supplied Codex composer screenshots as the visual target: one rounded input surface, a compact plus menu, an approval chip at left, and reasoning, microphone and circular send controls at right. Match the existing theme tokens, project navigation and full-width chat. Preserve manual/sample workflows and explicit plan approval.

The reasoning picker exposes Muse 1.4.13's documented none/minimal/low/medium/high/xhigh/max/ultra levels, default high. The model remains the official CLI's configured Muse model; no GPT branding or invented model catalog. Persist choices per task; new chats default to high and Ask me. A chosen level must reach the native exec arguments on each request.

Approval options: Ask for approval (:ask-me), Auto-review (:auto-review), and No prompts (approval-mode never, approval-judge off). All retain the Windows sandbox, configuration checks, disabled external tools/hooks, process ownership and revision gates. The menu explains that headless requests requiring a human decision stop; no fabricated interactive approval UI. Unrestricted is excluded because it disables the sandbox, contrary to the user's existing constraint. Changes affect the next request and are disabled while a turn is active.

Dictation uses the installed Windows System.Speech recognizer locally. A fixed native helper captures the default microphone only after the user clicks the mic. A visible listening state and Stop control bound capture to 90 seconds. Final recognized phrases append to the editable draft, never submit automatically, and do not become chat history until Send. No recordings or audio files are saved. Errors are actionable, with a manual typing fallback. Changing chat/project/product, opening a modal, hiding the window or closing the app stops dictation and rejects late text. The isolated main renderer receives a narrow speech IPC; remote Meta AI pages retain no bridge and no microphone permission.
